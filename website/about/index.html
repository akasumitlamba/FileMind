A small utility.
A clear purpose.

GROK stands for Graphical Resource Organization Kit — accessing and organizing resources through a graphical desktop interface.

Files come first

A compact right-edge dock keeps Windows files within reach. The application remains useful offline, without enabling AI or creating an account.

Why GROK?

The name describes the file utility. Optional integrations let you connect independent AI services from the same panel. GROK is not the official Grok service from xAI and is not affiliated with any provider.

Built for Windows

Python and PySide6 provide the desktop interface. Windows supplies credential storage, file associations, clipboard integration and shell properties. Version 1.0.0 targets Windows 10 build 19041 or later, and Windows 11, on x64.
