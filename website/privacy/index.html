Privacy policy

GROK is an independent Windows application made by akasumitlamba. This policy describes version 1.0.0 and its bundled static website.

Local file management

Browsing, filename filtering, clipboard operations and file management take place on your computer using your Windows permissions. GROK has no backend, mandatory account, cloud storage, analytics or telemetry. GROK does not upload filenames, documents, clipboard contents, screenshots or search queries as part of ordinary file management. Windows, network drives, sync software and default applications have their own behavior and policies.

Settings and credentials

Preferences, favorite folder paths, model IDs and default location are saved locally in settings.json under your Windows local app data GROK folder. Packaged Windows may redirect this folder into package data. These settings are not encrypted. API keys are saved separately in Windows Credential Manager for your Windows user. They are never written by GROK to settings, logs or crash reports. Processes running as your user may be able to access user credentials; this is not protection against a compromised computer.

Optional external AI

AI is disabled by default. When you enable it and press Send, your message and the current conversation are sent directly over HTTPS to OpenAI, Google Gemini or xAI, as selected. A connection test sends a short test message. Requests may incur your provider’s charges. Your key authenticates these requests.

Selecting files and clicking AI Chat queues them as removable attachments. You can also choose files using Attach. Before sending, you review their content. UTF-8 text files up to 100 KB and folder listings are supported; other formats cannot be sent. The provider receives that text when you send. GROK does not send tools that execute AI suggestions or change files. PDF and Office document extraction is not included.

Provider handling, retention and account controls apply independently: OpenAI privacy policy, Gemini API terms, and xAI privacy policy. GROK cannot promise that providers retain nothing. It requests no stored Chat Completions where supported; this does not override provider abuse monitoring or other retention.

Retention and control

Chat and sent attachment text are stored as unencrypted local JSON, separately per provider. History survives provider changes, disabling AI and app restarts. Clear chat deletes the selected provider’s local history. Requests already transmitted cannot be recalled by clearing chat. Settings persist until changed or deleted. Disconnect removes the selected credential from Windows Credential Manager. Remove credentials before uninstalling because they can survive uninstall. Files you create or change are retained at their destinations. Recycled items are managed by Windows.

Diagnostics

GROK creates no application telemetry, request logs or crash-report uploads. Windows and security software may collect their own diagnostics, memory dumps or network information.

Website

This site is static, with bundled images and system fonts. It sets no cookies, uses no analytics and has no forms or accounts. Opening external links contacts those sites. If the site is deployed, the chosen hosting service may process IP addresses and ordinary request logs under its own policy; no public host is configured in this local build.

Developer and changes

Developer: akasumitlamba. No support email or verified contact URL has been supplied, so none is invented here. Use the distribution channel through which you obtained GROK for support. Policy changes will update this page and its effective date. No certification or legal compliance evaluation is claimed.
