The build process copies the generated package here. A development package requires certificate trust; an unsigned package cannot be installed normally.

Install

  1. Read the supplied installation guide and verify the package checksum.
  2. For a signed development package, trust only the supplied development certificate on a test machine you control.
  3. Open GROK.msix with Windows App Installer, or use Add-AppxPackage after certificate trust is configured.
  4. Launch GROK from Start. Click the dock, or use Ctrl+Alt+G.

Validation limits

See the project’s QA report for the exact executed checks. Live provider calls require your API account and are not certified by fixture tests. Physical monitor reconnection, every DPI/taskbar combination, network drives and Windows drag/drop interoperability need testing on your target setup.

Portable alternative

The project also produces dist/GROK/GROK.exe. Keep its accompanying _internal folder beside it. The portable build does not require MSIX certificate trust.
